# Archief

Bronmateriaal dat de website op dit moment niet gebruikt.

Deze bestanden staan bewust **buiten** `public/`: alles in `public/` gaat
mee in de statische export en komt dus op assaultboats.nl te staan. Wat
hier ligt blijft bewaard, maar wordt niet online gezet.

- `merch/` — de merch-afbeeldingen en de contactsheet. De merch-sectie is
  van de site gehaald; zet de bestanden terug in `public/images/merch/`
  als de sectie terugkomt.
